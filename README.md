# Wasteland — Toolbox

A personal collection of browser-first utilities, small web apps, experiments, and offline scripts for images, audio, PDFs, maps, text, metadata, 3D, and more.

**Live site:** [ubuv6vvyv.github.io/Wasteland](https://ubuv6vvyv.github.io/Wasteland/)

Open any hosted tool from the categorized links below, or open an HTML file locally in a modern browser. Some tools need a local HTTP server or an internet connection to load dependencies or models.

### Python and offline utilities
Scripts in the [`Python/` folder](https://github.com/Ubuv6vvyv/Wasteland/tree/Index/Python) cover PDF generation, file organization, timelapse, and video tiling. Other repository scripts include audio and image utilities. See the [categorized tools index](https://github.com/Ubuv6vvyv/Wasteland/blob/Index/TOOLS_INDEX.md) for more inventory notes.

## Using the tools
- Open a hosted link above, or open an HTML file locally in a modern desktop browser.
- Some machine-learning demos load models from the network. GitHub Pages or a local HTTP server is recommended; for example, run `python -m http.server` from the repository root and visit `http://localhost:8000`.
- Run Python utilities with Python 3.9+ where applicable, for example: `python3 Python/gallery.py`.

## Notes
These are personal, often experimental tools rather than a polished product. Use caution with file uploads, and when crawling or scraping, follow each site's robots.txt and terms of service. Some tools may require network access, permissions, or additional setup.
