# Wasteland — Toolbox

A personal collection of browser-first utilities, small web apps, experiments, and offline scripts for images, audio, PDFs, maps, text, metadata, and more.

**Live site:** [ubuv6vvyv.github.io/Wasteland](https://ubuv6vvyv.github.io/Wasteland/)

Open the hosted tools from the links below, or open an HTML file locally in a modern browser. Python scripts require a local Python environment.

## Using the tools
- Open a hosted link above, or open an HTML file locally in a modern desktop browser.
- Some machine-learning demos load models from the network. GitHub Pages or a local HTTP server is recommended; for example, run `python -m http.server` from the repository root and visit `http://localhost:8000/color-app/index.html`.
- Run Python utilities with Python 3.9+ where applicable, for example: `python3 Python/gallery.py`.

## Notes
These are personal, often experimental tools rather than a polished product. Use caution with file uploads, and when crawling or scraping, follow each site's robots.txt and terms of service. Some links are source files or experiments rather than standalone hosted web apps.
